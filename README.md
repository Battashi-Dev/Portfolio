# Portfolio

A modern, responsive portfolio website built with React and TypeScript to showcase my work, skills, and featured projects. This project is designed to present a professional and polished overview of my development experience in a clean, user-friendly interface.

## Overview

This portfolio serves as a personal landing page for my work as a developer. It highlights key projects, demonstrates technical capabilities, and provides an easy way for recruiters, collaborators, and clients to explore my work.

## Featured Project

- Expensive Tracker — A React + TypeScript expense tracker with localStorage persistence, Zod validation, and React Hook Form. Built with custom hooks and Chakra UI for a modern user experience.

## Tech Stack

- React
- TypeScript
- Vite
- Chakra UI
- React Hook Form
- Zod

## Features

- Responsive and modern UI
- Project showcase with GitHub and demo links
- Clean, component-based architecture
- Type-safe development with TypeScript
- Easy to customize and extend

## Getting Started

1. Clone the repository

   ```bash
   git clone <your-repo-url>
   cd portfolio
   ```

2. Install dependencies

   ```bash
   npm install
   ```

3. Start the development server

   ```bash
   npm run dev
   ```

4. Open your browser and visit:
   ```text
   http://localhost:5173
   ```

## Build for Production

To create a production build:

```bash
npm run build
```
